# OpenSpec (frozen)

This folder is a historical record of the specs and changes made up to
November 2026. It is **no longer maintained**: some requirements here are out of
date (for example, `specs/match-data/spec.md` still requires exactly three
leagues).

New specs and tickets live as GitHub issues. See `docs/agents/issue-tracker.md`
and the `## Agent skills` section of `AGENTS.md`.
